# Contributing to Qraft

Thanks for helping improve Qraft. Good contributions make question authoring more useful, reliable, or easier to operate.

1. For a substantial change, open an issue describing the user problem and the smallest useful outcome.
2. Develop on a branch. Keep generated files, local settings, model keys, and release binaries outside Git.
3. Add focused tests for behavior that can regress; prefer real invariants over tests that copy the implementation.
4. Run the checks relevant to the change and explain the result in the pull request. Use synthetic test data.
5. For interface changes, include a screenshot at a stated window size and check both desktop and Web behavior.

See [Development](docs/development.md), [Architecture](docs/architecture.md), and [Third-party notices](THIRD_PARTY_NOTICES.md).

Contributions are provided under the repository's MIT license. Do not contribute material you do not have permission to publish.
