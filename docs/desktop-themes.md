# 桌面主题使用与扩展

Qraft 的六套内置配色同时用于 Web 和桌面；自定义主题、JSON 导入导出与界面密度由桌面客户端提供。

## 日常切换

点击窗口右上角的 **外观与主题**，可在当前页面直接切换主题，无需跳转或重载，正在填写的表单会保留。按 Esc 或点击弹层外关闭；键盘可用 Tab 移动、Enter 选择。

- **颜色主题**：石墨、海湾蓝、鸢尾紫、松林绿、玫瑰、琥珀。
- **明暗模式**：浅色、深色、跟随系统。明暗模式与颜色主题分别保存；每套颜色都有完整的浅色、深色配色。
- **管理主题**：进入客户端设置的“外观”，查看预览卡片、管理自己的配色及调整界面密度。

主题也应用于业务页面和代码编辑器。跟随系统时，界面与主题预览会一起更新。

## 创建、分享与保存

在“客户端设置 → 外观”操作：

1. **创建主题**：填写名称，选择强调色。背景、文字等颜色继承当前主题；点击“保存并应用”完成创建。
2. **导出当前主题**：使用原生“另存为”保存 JSON。可直接分享文件，也可编辑两套完整配色后重新导入。
3. **导入主题**：选择 JSON 文件。验证通过后另存为一个自定义主题并应用，文件里的 ID 不会覆盖已有主题。格式或可读性不合格时显示原因，当前主题保持不变。
4. **删除主题**：点击自定义卡片的删除按钮。删除当前主题后回到石墨，保留所选明暗模式。内置主题不可删除。

最多保存 **12 个自定义主题**。选择、创建和删除自动保存到本机客户端数据目录的 `ui-preferences.json`；重启后继续沿用。保存失败会提示并恢复上次成功保存的偏好。新安装默认海湾蓝，与 Web 保持一致。已有偏好的明暗模式、密度、侧栏状态和配色继续保留；旧版文件缺少颜色主题字段时仍兼容为石墨，不覆盖用户选择。

## 主题 JSON

以下是一个可导入的完整示例：

```json
{
  "schema": "algoforge.desktop-theme",
  "version": 1,
  "id": "custom-study",
  "name": "书房",
  "colors": {
    "light": {
      "accent": "#7452B8",
      "background": "#F6F7F9",
      "surface": "#FFFFFF",
      "sidebar": "#FAFBFC",
      "text": "#20242C",
      "muted": "#606875",
      "border": "#E1E4E9"
    },
    "dark": {
      "accent": "#B9A1EE",
      "background": "#16181D",
      "surface": "#1D2027",
      "sidebar": "#191C22",
      "text": "#ECEEF3",
      "muted": "#A7AFBE",
      "border": "#343943"
    }
  }
}
```

| 字段 | 含义 |
| --- | --- |
| `accent` | 强调色与主要按钮 |
| `background` | 页面背景 |
| `surface` | 卡片、输入区与编辑器背景 |
| `sidebar` | 侧栏背景 |
| `text` | 正文 |
| `muted` | 次级文字 |
| `border` | 分隔线与边框 |

导入要求：

- 文件不超过 **16 KB**；结构、版本和字段必须与示例一致，同时提供 `light` 与 `dark`。
- 颜色只能为六位十六进制 `#RRGGBB`，不区分大小写。不支持透明度、CSS 表达式、脚本、链接或附加字段。
- 名称为 1–40 个可见字符；ID 以小写英文字母开头，只含小写字母、数字和短横线，总长不超过 64 个字符。导入时会生成新的自定义 ID。
- 两种模式中，`text` 和 `muted` 对 `background`、`surface`、`sidebar` 的对比度都须达到 **4.5:1**。
- 按钮文字自动选择黑或白；标签、链接会采用可读的强调色变体，因此浅黄色等强调色也可以使用。

只调整强调色时，优先使用界面的创建功能；需要改变整套背景和文字时，再编辑 JSON。

## 开发者增加内置预设

无需增加依赖或插件系统。在以下位置同步维护同一个内置 ID：

- [frontend/src/desktop/themes.ts](../frontend/src/desktop/themes.ts)：在 `BUILTIN_THEMES` 中增加名称及两套完整配色。设置卡片与顶部快捷选择会自动读取该列表。
- [desktop/internal/app/themes.go](../desktop/internal/app/themes.go)：在 `builtinThemeIDs` 中加入相同 ID，使本机偏好校验接受它。

主题通过语义 CSS 变量、业务色阶和编辑器主题统一应用；新组件应使用这些变量，避免写死某套主题的颜色。JSON 版本与字段变更需同步前端、Go 校验及兼容读取逻辑。

修改后运行对应主题测试，并在浅色、深色及跟随系统下检查真实界面：

```bash
(cd frontend && node --test src/desktop/themes.test.cjs)
(cd desktop && go test ./internal/app)
```

增加预设数量时，同时调整主题测试中的预设数量断言，保留全部配色的可读性检查。
