# 外部来源导入与题集测试包

在侧栏打开 **链接与题目导入**。Web 与桌面客户端使用同一业务页面；旧客户端需要更新到包含该页面的构建。

## 两种处理方式

- **原题导入**：保留原题意、公式、约束和全部原样例，由管理员配置的模型整理成标准 OJ 题面。先去重，再生成新的测试数据、参考解法和暴力校验程序，经过编译、沙箱执行与有界差分后保存。固定使用四级标题“题目描述 / 输入格式 / 输出格式 / 输入输出样例 #n / 输入 #n / 输出 #n / 数据规模与约定”，样例使用代码块。清理网页噪声并修复排版，具体歧义只作必要澄清；原文、来源、哈希、结构化排版内容和修订原因保存在题目来源记录中，不经过原创性评审或换题循环。
- **作为创意生成**：将来源正文作为参考素材，走现有完整生成与验证流程，产生新的题面与数据。来源内容不会获得系统指令权限。

两种方式都重新生成测试数据，不下载或复用来源网站的原测试包。新导入任务的原题样例全部保留在题面，并分别用参考解法和独立解法核对；确实没有原样例时，模型补充至少一个小样例，同样需要两份解法校验。未给出的数值约束明确注明，不凭空补造范围。原题导入由工作流模型直接给出难度估计，不运行 KC 对齐或难度迭代；估计失败只记录警告，不阻塞已验证题目入库。作为创意生成仍走原有质量流程。

定点小数题的解法生成要求按题面约定处理精度与舍入；有限十进制输入优先使用整数缩放或精确分数。数据规划要求覆盖舍入中点及两侧合法输入，并将这些输入纳入有界差分子集。样例与独立解法不一致会触发修复，持续不一致则不入库。既有题目与进行中的旧任务不会自动改写；历史题目的修复需要重新执行校验。

## 单题和题集

粘贴一个或多个公开链接并解析。公开 Codeforces、AtCoder 和 Hydro 的常见题面、题目列表，洛谷和牛客练习题的公开题面，以及通用 HTML/Markdown 可以读取；题集页只展开成员列表，随后读取选中的成员，不递归爬站。网站可能有登录、反爬或动态渲染限制，无法读取时请直接粘贴完整 Markdown 题面。

洛谷题面读取同一公开页面内的原始 Markdown 与样例，避免 HTML 摘要把 `<` 不等式截断或遗漏样例；无法取得完整结构时明确提示，不使用截断摘要继续生成。已保存的历史导入清单不会被自动覆盖。

一次最多 50 题。单题正文最多 128 KiB，标题最多 200 个 Unicode 字符，整批正文最多 1 MiB；题集名称最多 255 个 Unicode 字符。清单可以继续追加来源、取消选择、逐项删除，并预览正文。点击“粘贴替换”可以修正任意条目的标题和正文，保留来源与其他条目；保存前暂不能提交，避免遗漏编辑内容。删除后可在“粘贴题面”中补入新题。来源读取失败会单独列出，其他可用题目继续提交；失败来源可单独重试。

每批最多并行处理三题，实际执行速度还受服务端 worker 并发限制。重复项返回“重复，已跳过”，不写入新题，也不阻塞后续条目。相同标题不构成重复判据。原文完全相同或经语义核验确认等价的题目会跳过；歧义修订不会丢失原始来源的查重身份。并发导入相同原文也不会产生两条成功记录。

每道题独立记录结果：

| 状态 | 含义 |
| --- | --- |
| 等待 / 处理中 | 后台正在处理，可关闭页面后返回 |
| 已导入 | 题目、新数据与难度评估已完成 |
| 重复，已跳过 | 题库或本批已有相同题目，没有再导入 |
| 失败 | 本题未完成，其他题继续 |
| 难度估计警告 | 题目和数据已保留，难度估计未完成；不会阻塞其他题目 |

勾选“将成功题目汇成题集”后，成功生成的题目按原清单顺序加入新题集。被跳过的重复题不会自动加入，评估失败但数据已验证的题目会保留并标明待处理。导入任务保留自己的进度链接，访问权限与任务所有者绑定，管理员可以管理。

若题目已建档、数据保存中断，系统会提示原任务尚未完整保存，不会把半成品当成成功重复项。可在对应生成详情中重试保存；恢复后的题目从该任务或题库查看。批次结束后可使用“继续未完成项目”：保留已完成题目、重复跳过记录和原题集身份，只继续未完成项，最后按原清单顺序整理同一题集。

## 两个 ZIP 下载按钮

题集详情提供两个用于测试的下载按钮。下载不会将草稿改为已发布，也不会作为正式出卷写入复用冷却记录；数据仍必须有可核验的沙箱执行与差分证据，文件缺失、哈希不符、题面已变或数据未就绪时明确报错。

**通用 ZIP** 按 Excel 导入模板版本 2 打包，保留编程、选择、填空和判断题。ZIP 根目录只有一个 `problems.xlsx`，其中“题目列表”严格使用 19 列导入字段，“测试点配置”使用 12 列测试点字段。编程题数据位于 `datas/题目编号/`，题目编号、测试点文件名和 Excel 逐项对应。上传整个 ZIP，无需手动拆分或再压缩。

```text
problems.xlsx                  # 题目列表、测试点配置、导出说明
datas/C…/1.in                  # 编程题输入输出，文件名与测试点表对应
datas/C…/1.out
problems/001/statement.md       # 无损 Markdown 题面
problems/001/judge.json         # 数据路径（相对 ZIP 根目录）、哈希、验证摘要
problems/002/question.json      # 客观题完整信息与来源侧语言配置
problem-set.json               # 原始题集顺序、分值、来源题号、rating、导入题号
export-notes.json               # 难度转换与未匹配标签说明
README.txt
```

题号由题集身份和题序稳定生成，分别使用 `C/X/T/P` 前缀。同一题在一套题集中出现多次也不会覆盖文件。编程题填写模板版本 `2`，时间和内存分别使用 `s/ms`、`m` 单位。测试点保留现有 `sum/min` 子任务计分、时间及内存限制；`sum` 各点分数之和必须等于子任务分数，`min` 留空点分数。样例保留既有零分规则。题集分值仍由目标 OJ 的比赛配置决定，不改写题目的内部计分。

选择题选项与多个答案使用 `{break}` 分隔；填空题保留 `{break}` 和同一空的 `{or}`；判断题使用“对/错”。题面、公式、代码与解析保留原文。超过 Excel 单元格的 32767 UTF-16 单元上限时明确拒绝，避免无声截断。

### 自定义导出编号

在题集详情展开“导出题目编号”并启用自定义编号，可设置前缀与起始编号。例如前缀 `Demo`、起始编号 `50`，编程题将依次使用 `DemoP050`、`DemoP051`。编号至少补足三位，超过 999 后自然延长；前缀最多 24 个英文字母、数字、下划线或连字符，编号范围为 1–999999，整套题的末尾编号也必须在范围内。

通用 ZIP 的 Excel 题目编号、测试点配置与数据目录保持一致；Hydro ZIP 的 `problem.yaml` 使用同一编号，目录仍按题序排列。混合题集中的客观题使用现有的 `X/T/P` 类型标记，所有题型共用递增题序。关闭此选项时沿用默认稳定题号。设置仅影响本次下载，不改写题库题号；连续导入多个题集时请使用不同前缀或不重叠的编号范围。

### 标签目录

在题集详情展开“通用 ZIP 标签映射”，选择目标 OJ 导出的标签 JSON（包含 `activeTagsTree`）。文件仅用于当前页面的下载，不保存为全局配置，不发送给模型。导出仅匹配有效且未删除的标签，优先匹配精确 ID、完整树路径，再匹配唯一名称。层级按父子树重建，不依赖可能过期的层级字段。

标签 ID 全程按字符串处理。存在同名、已删除或无法匹配的标签不写入 Excel 标签列，原始标签和待处理说明保留在包中；其他标签和题目继续导出。不选择目录时标签列留空，原始标签仍然保留。生产标签、私人模板和语言目录不随公开源码分发。目标语言 ID 尚未确认时不限制语言，不把参考解法填成用户代码提示。

### 六档难度

这是 Qraft 为此导入格式采用的分档规则，不改变正式 rating，也不代表外部平台的官方评级。

| Qraft rating | 导出档位 |
| --- | --- |
| 800–999 | 入门 |
| 1000–1399 | 简单 |
| 1400–1799 | 进阶 |
| 1800–2199 | 困难 |
| 2200–2599 | 挑战 |
| 2600–3500 | 地狱 |

缺失或超出有效范围的 rating 留空并说明。客观题 `easy/medium/hard` 分别导出为“简单/进阶/困难”。原始 rating、客观题难度和转换说明保留，便于核对。

### Hydro ZIP

**Hydro ZIP** 用于纯编程题集。每道题是 ZIP 根目录下的 001/、002/ 等目录，内含 problem.yaml、题面和 testdata；不是 ZIP 套 ZIP。在 Hydro 的题库导入入口选择 Hydro 格式上传整包，之后按题集清单配置比赛题序与分值。混合题型不能下载 Hydro 包，避免静默丢失客观题。

当前支持普通文本输出判题；特殊判题、交互题和输出答案题不在此测试包范围内。现有正式发布导出接口及门禁保留。

## API

所有路径均加 /api/v1 前缀，并沿用当前账号会话与 CSRF 约定。成员可创建、查看自己的导入任务；管理员可管理，客户端不能指定所有者或覆盖服务端模型凭据。

- POST /sources/preview：请求字段 url，返回来源、正文或题集成员。抓取限制为公开 HTTP/HTTPS 地址；每次连接和重定向复核地址，不携带账号 Cookie、Authorization 或代理凭据。
- POST /problem-imports：字段 mode（preserve_statement 或 inspiration）、items、create_set，以及可选 title、difficulty、language、locale。items 的每项包含 item_id、title、statement，可选 source_url 和 source_id。返回 202 与 workflow_id。
- GET /problem-imports/:id：返回任务状态、逐题结果、计数与可用的 problem_set_id。结果中的 problem_id、rating_assessment_id、statement_changed 和 clarification_reason 用于跳转或解释修订。
- GET /problem-sets/:id/export.zip?mode=testing&format=generic：模板兼容的通用测试包，无目标标签映射。
- POST /problem-sets/:id/export.zip?mode=testing&format=generic：同一格式，可携带 `{ "tag_catalog": { "activeTagsTree": [...] } }`，请求最多 1 MiB。沿用题集访问权限与会话 CSRF 校验；仅影响本次导出。格式标识为 `qraft.problem-set.testing.generic.v2`。
- GET /problem-sets/:id/export.zip?mode=testing&format=hydro：Hydro 测试包。

以上测试包 GET/POST 接口均可附加查询参数 `id_prefix=Demo&start_index=50`；只传前缀时从 1 开始，只传起点时前缀为空。两个参数均不传时保留原默认题号。非法前缀、编号或整套编号越界返回 400；正式发布导出不接受这两个参数。

完整字段与兼容性约定见 [API 文档](api-reference.md)。


## 原题导入的参考难度与恢复

新建及恢复的外部导入使用 `direct_difficulty=true`：题面检查、去重、新数据生成、标程与独立解法验证后直接入库，再由模型给出一次参考难度。沿用题库 800–3500 的数值字段，标注为主观模型估计，不与 Codeforces 或历史锚点对齐，不自动启动 KC 评估工作流。估计失败只产生提示，不影响已经保存的题目和数据；独立的题目评估板块继续保留。

去重比较及难度估计每次最多等待 2 分钟；标准 OJ 题面整理、测试数据和解法生成每次最多等待 5 分钟。结构错误最多进行两次独立修复。普通活动重投复用已留存响应，修复请求使用独立调用标识，避免反复使用同一份坏响应。数据响应必须具有完整顶层 `test_cases` 数组，不能把内部生成器对象当作整个响应。

`POST /api/v1/problem-imports/:id/resume` 仅允许当前用户有权查看的已结束批次。服务端读取原始输入和结果，刷新模型配置，保留已入库和重复跳过的项目，仅重新处理未完成项目；旧版评估失败的已入库题目不重新生成。恢复使用确定性任务编号，重复点击返回同一恢复任务；仍在运行的批次返回 409。成功项目继续汇入原题集身份。旧任务保留其历史执行路径，避免破坏任务回放。

原题导入的题面检查、去重比较和数据规划沿用管理员配置的模型，仅将高于中等的推理档位收敛为 `medium`，避免简单的数据计划长时间等待；参考解法及独立验证继续沿用原推理档位。此局部预算不会改写已保存的模型配置。

模型请求超时可由活动既有的“两次尝试”策略自动重试一次；不会无限重试。已经完成的模型调用仍复用缓存，只有格式错误触发独立修复请求。估分活动仅尝试一次，失败不阻塞导入。

## 任务列表分页

任务中心使用服务端返回的分页位置读取下一页，页码从 1 开始；上一页可返回已浏览的位置，切换筛选或每页数量回到第一页。不把缺失的总数显示成 0。每一页仍逐项验证任务所有者权限。
