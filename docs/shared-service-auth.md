# 共享服务：账号与权限

> 本文对应 V2.3.0 团队账号模块，需要配套客户端与服务端。旧 V2.2.x 发行包不具备完整账号流程。

云服务器上的 HTTPS 入口、首次配置与邀请验收见[公网部署指南](cloud-deployment.md)，支持公网 IPv4 或域名。

一台服务提供一个团队共享题库。成员可以创作、组卷和管理自己的任务，管理员统一管理账号、模型、共享内容及正式评级。首期只有 `admin` 和 `member` 两个角色。

## 初始化管理员

源码部署执行 `python3 scripts/configure.py` 时会生成随机初始化令牌，保存在当前实例的 `.env`。已有文件保持原样；从旧开发模式转为共享服务时明确执行：

~~~bash
python3 scripts/configure.py --shared
~~~

该命令设置 `APP_DEV_MODE=false`、`QRAFT_AUTH_SECURE_COOKIE=true`，只在缺失时生成初始化令牌，不重启服务、不更换数据库或模型密钥。按[部署指南](self-hosting.md)重建匹配源码的 API、Web 和 worker，并应用新增迁移。

- 对外提供一个 HTTPS 根地址，代理同时转发 Web 和 `/api/*`。数据库、Temporal、MinIO 管理和沙箱端口保留在内部网络或回环地址。
- 同源使用无需设置 `QRAFT_ALLOWED_ORIGINS`；确需独立 Web 地址时，仅填写受信任的完整 origin，不允许通配符。Cookie 的 SameSite 限制仍适用。
- `QRAFT_AUTH_SECURE_COOKIE=false` 仅用于源码默认的本机 HTTP 测试；对外服务必须使用 HTTPS 和 Secure Cookie。
- `APP_DEV_MODE=true` 使用本机管理员身份，不能用于公网共享服务。桌面管理的个人本机实例继续使用它，入口只绑定回环地址。
- 不要公开初始化令牌、邀请链接、Cookie、`.env` 或用户数据。

在自己的私密终端查看令牌：

~~~bash
python3 scripts/configure.py --show-bootstrap-token
~~~

首次打开工作区，填写初始化令牌、管理员邮箱、显示名称和密码。令牌不进入 URL。数据库已有任何账号后，初始化接口不能再次创建管理员；不存在首个访问者自动成为管理员的行为。完成后可从部署环境移除初始化令牌，在下次正常重启应用。

## 邀请用户

1. 管理员打开 **成员管理**，填写邮箱并创建注册邀请。
2. 复制一次性邀请链接，通过自己选择的渠道发送给对应用户。
3. 用户打开链接并设置密码，然后登录 Web，或在客户端保存相同服务地址后登录。

邀请绑定邮箱、设有有效期、只能使用一次，管理员可随时撤销。首期不依赖 SMTP，也没有公开注册。持有邀请链接是注册凭据；管理员需核实接收人，系统不另外证明其邮箱所有权。

密码至少 12 个字符、最多 72 个 UTF-8 字节，支持密码管理器粘贴。遗忘密码时，管理员创建该邮箱的“重置密码”邀请。修改或重置密码会撤销所有旧会话，之后重新登录。

## 权限

| 操作 | 成员 | 管理员 |
|---|---|---|
| 浏览、搜索、导出已共享题目 | 允许 | 允许 |
| 发起编程题、客观题、题集生成和组卷 | 允许 | 允许 |
| 任务详情、事件、重试、取消、生成中审阅 | 自己的任务及子任务 | 全部 |
| 查看未共享生成结果 | 自己的结果 | 全部 |
| 管理自己创建的题集 | 允许 | 全部 |
| 编辑、删除、公开发布共享题目 | 禁止 | 允许 |
| 模型、去重和审核策略配置 | 禁止 | 允许 |
| Rating 分析管理、评题邀请、正式改分 | 禁止 | 允许 |
| 邀请、停用、恢复账号和调整角色 | 禁止 | 允许 |
| 修改自己的密码、退出 | 允许 | 允许 |

停用、角色调整与密码变更立即影响后续请求。系统禁止停用或降级最后一个有效管理员。历史任务没有可信所有者时，只向管理员开放，不自动分配给新账号。

成员只能使用管理员保存的模型配置。客户端不能指定环境密钥引用，也不能借请求把服务器密钥转发到其他地址。题库公开内容与完整生成记录分别控制权限；知道任务 ID 不代表拥有访问权。

## 会话与客户端

首次启动不预设服务，保存地址之前不请求账号接口。连接检查区分“可达但待登录”和网络失败。客户端设置、本机部署入口、公共评题页始终可以独立访问。

Web 使用 HttpOnly Cookie；桌面原生代理按服务 origin 隔离 Cookie。切换服务清理前端账号和页面状态。桌面会话仅在进程内保存，完全退出软件后重新登录。

写操作携带会话绑定的 CSRF token；会话不放在 localStorage 或 SSE 查询参数中。退出先撤销服务端会话。401 提示重新登录并保留未提交页面，403 提示权限不足，不把所有操作重定向到客户端设置。

旧服务不能仅因缺少账号接口就被视为匿名管理员。远程旧服务需升级匹配后端；桌面受管、已配置的回环本机服务保留明确的旧版兼容路径。

公共 `/rating/review` 使用独立评题令牌，不继承管理员 Cookie，也不具有注册权限。成员可能已在共享题库见过解答，因此隐藏评题页面内容不代表该成员从未接触题目。

## 运维与验证

新增迁移以追加方式创建账号、会话、邀请、审计和归属记录，不导入旧产品账号。备份数据库及原有设置加密密钥；数据库只保存会话与邀请令牌的摘要。

仓库包含角色矩阵、账号事务和任务权限回归测试。部署后可用管理员、成员 A、成员 B 检查邀请、登录、停用、重置密码及跨用户任务访问。

设计参考：[OWASP 认证](https://cheatsheetseries.owasp.org/cheatsheets/Authentication_Cheat_Sheet.html)、[会话管理](https://cheatsheetseries.owasp.org/cheatsheets/Session_Management_Cheat_Sheet.html)、[授权检查](https://cheatsheetseries.owasp.org/cheatsheets/Authorization_Cheat_Sheet.html)。本期不包含多租户、组织层级、邮件服务器或多实例高可用。
