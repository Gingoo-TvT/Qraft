## #15 入门题不应附带无关精度陷阱

修复包含两部分：出题、解法、测试生成与审核共同遵守数值难度范围；原题样例由主解和独立解法共同核对，持续不一致则拒绝入库，不静默改掉来源样例。

- 普通算术与格式化题的生成数据避开只区分浮点表示的中点陷阱，同时保留一般小数、上下舍入、进位、零和尾随零。
- 明确考察精确小数或数值稳定性的题目仍保留其真实要求，不能随意放宽 checker。
- 工作流回归覆盖原题/补充样例的双解法校验及不一致时有限修复后失败，不产生有效入库结果。
- 本地实际编译普通 C++17 浮点程序，与独立精确分数算法核对 3000 个合成、条件良好的算术用例，全部一致。该验收不是“所有模型生成内容都正确”的证明。
- 历史审核提示身份、老任务和证据兼容回归通过。

结论：按确认的“难度对齐 + 样例一致性门禁”范围，#15 源码验收通过，可以关闭。已有线上题目、测试点和验证证据未被本次验收修改；更新源码不会自动修复旧数据。
