# Qraft · 题构 — Windows 使用指南

Qraft 在 Windows 原生窗口中提供出题、题集、组卷与题库管理。界面随 EXE 打包；首次启动显示使用方式选择，不预设或自动连接任何服务。

## 下载与安装

在 [V2.3.0 Release](https://github.com/Gingoo-TvT/Qraft/releases/tag/v2.3.0) 下载安装版或便携包；本次变更见[发行说明](releases/v2.3.0.md)。

- 安装版：运行 `Qraft-2.3.0-windows-x64-setup.exe`。
- 便携版：解压 `Qraft-2.3.0-windows-x64-portable.zip`，运行 `Qraft.exe`。
- 独立 EXE：适合已安装 Microsoft WebView2 Runtime 的电脑。
- 后端镜像包：仅自行部署时需要。V2.3.0 Release 提供配套 V2.3.0 后端包，升级前备份并等待任务结束。

客户端需要 [Microsoft WebView2 Runtime](https://developer.microsoft.com/microsoft-edge/webview2/)。安装包与便携包附带微软的安装引导程序；缺少 Runtime 时需联网安装。离线电脑可预先安装微软官方 Evergreen Standalone Runtime。

## 连接已有服务

1. 首次页选择 **连接已有服务**。
2. 填写管理员提供的根地址，例如 `https://qraft.example.org`。不要追加 `/api/v1` 或其他路径。
3. 点击 **连接工作区** 保存地址。进入工作台后会自动检测；连接失败时，可在 **客户端设置 → 服务连接** 修改地址。

远程使用者不需要安装 Docker、WSL、数据库或编译器。`localhost` 指当前这台电脑，不能用它连接别人的电脑。切换服务时会清除上一服务的页面缓存，避免混用题目与任务。

V2.3.0 提供完整的共享服务登录：保存兼容服务地址后，使用管理员邀请注册的邮箱和密码登录；服务可达但未登录会显示登录提示。账号功能必须与 V2.3.0 后端配套，详见[账号与权限](shared-service-auth.md)。桌面关闭后会话不落盘，重新启动需要再次登录。第三方跳转式认证网关仍不在本期支持范围。

## 在本机自行部署

需要 Docker Desktop 的 **Linux 容器模式**。WSL 2 是 Docker Desktop 的一种后端选择，不需要进入 WSL 操作代码。模型通过 API 调用，无需本地 GPU；建议为服务预留至少 8 GB 可用内存和 15 GB 磁盘。

1. 启动 Docker Desktop。
2. 首次页选择 **在本机自行部署**，点击 **开始部署**；默认端口为 `18180`。
3. 在本地后端页选择配套的 `Qraft-2.3.0-backend-linux-x64.tar.gz`，导入并校验。
4. 启动本地后端，等待配置工作区就绪。
5. 在 **模型配置** 保存生成与审查模型，在 **去重服务** 测试并保存 embedding 设置。
6. 返回本地后端页，应用已保存的去重配置并启动生成服务；按去重页提示完成所需启用操作。

本机后端尚未就绪时，业务页面仍可打开并填写需求，页内会提示连接或前往本地后端；读取题库、保存配置和提交任务仍需服务可用。停留在当前页面时，连接状态恢复会保留已填写的需求；创建题目页可点击 **重新加载标签** 重试，无需刷新整页。

首次配置前不会自动调用模型。新库不带题目、任务、历史模型配置或密钥，只包含程序所需的基础字典与规则。

服务入口默认是 `http://localhost:18180`，数据库和沙箱不直接发布主机端口。Docker 项目为 `qraft-desktop`。客户端只管理本数据目录创建的资源；端口被占用或发现外来容器、数据卷、网络时会拒绝接管。选择其他空闲端口或使用现有实例所属的客户端目录，不要删除不明资源。

## 数据保存在哪里

| 内容 | 位置 |
|---|---|
| 安装版 / 独立 EXE 的客户端资料 | `%LOCALAPPDATA%\Qraft` |
| 便携版资料（保留 `portable.flag`） | 程序旁的 `data-qraft` |
| 地址与端口 | `settings.json` |
| 主题、密度与导航偏好 | `ui-preferences.json` |
| 本机部署凭据与归属 | 客户端资料下的 `backend/.env` |
| 实际题库与任务 | 所连接服务的 PostgreSQL、Temporal、MinIO 数据卷 |

安装包和便携包都不包含上述实例资料。Qraft 不会自动导入其他产品的目录、连接或题库；也不会把独立实例的题目合并到公共题库。

## 创作与导出

- 工作台支持单道编程题、混合题集与纯编程比赛，需求会带入创建页确认。
- 题库组卷可先预览缺口再保存，不调用模型。
- 六套配色与明暗模式可即时切换，编辑中的内容保留；详见[主题扩展](desktop-themes.md)。
- 在工作台、题库、题目创建/详情与题集页面，Ctrl K 聚焦顶部 **搜索题目**，按 Enter 同时检索编程题与客观题。模型配置、去重服务、客户端设置和导出记录等工具页面隐藏此入口。
- 搜索支持题号、标题、标签、知识点的部分文字匹配；结果可按题型、标签、知识点和难度组合筛选，翻页与返回保留条件。编程题评分（800–3500）和客观题难度（简单/中等/困难）分别筛选，不换算。
- 统一搜索需要 V2.2.0 服务端提供相应接口；完整功能需要 V2.3.0 后端。连接的服务早于 V2.2.0 且缺少接口时，会提示升级服务端，并提供原题库入口。
- Ctrl Shift K 打开快捷操作，Ctrl N 创建题目，Ctrl Shift N 生成题集。
- 在“链接与题目导入”选择原题导入或创意生成，支持公开题目/题集链接和粘贴题面，测试数据全部新生成。
- 题集详情分别下载“通用 ZIP”和“Hydro ZIP”：通用包保留混合题型与 .in/.out，Hydro 包按单层目录整包导入纯编程题。参见[导入与测试导出](source-import-export.md)。
- 下载使用 Windows 原生保存对话框，可从导出记录查找保存结果。

## 关闭、备份与升级

关闭客户端会停止其界面进程，后端任务继续运行。需要停止本机服务时使用 **安全停止**；它先等待 worker 收尾，再停止依赖，最长可能等待 40 分钟。

### 更新客户端

在 **客户端设置 → 关于 → 客户端更新** 中操作：

1. 点击 **检查更新**，获取本仓库最新正式版本；首次启动不会自动联网检查。
2. 有新版本时点击 **下载更新**。界面显示进度，检查和下载均可取消；下载完成后自动核对大小与 SHA256。
3. 保存正在编辑的内容，点击 **安装并重启** 并确认。安装版更新到原安装位置，便携版和独立 EXE 替换原程序，重启后继续使用原数据目录、连接与外观设置。

更新期间不能同时导出文件或管理本机后端。无法访问 GitHub、下载中断或校验失败时，当前客户端仍可使用，可以重试或从发布页手动下载。替换前会备份原 EXE；失败时尝试恢复原程序，结果会在“客户端更新”中显示。备份位于客户端资料目录的 `updates/pending-*/previous-client.exe`，不是题库备份。

**v2.2.0 可使用上述内置更新升级到 V2.3.0。旧版 v2.1.0 没有内置更新入口，首次需要手动安装新版客户端。** 安装版关闭旧客户端后运行新版安装包；便携版关闭程序、备份原目录后，用新版便携包替换程序文件，保留原来的 `data-qraft` 和 `portable.flag`。此后才能在客户端内完成更新。

### 升级后端与备份

客户端内置更新只更换 Windows 客户端，不会停止或升级本机、远程服务。后端仍可继续执行任务；升级服务时应先等待任务结束并备份，再按目标版本说明导入后端包。连接已有服务时，后端升级由管理员处理。V2.3.0 同时更新客户端和后端，并新增人工审核迁移。请按[发行说明](releases/v2.3.0.md)升级配套服务，保留实例凭据、数据库和对象文件，不重新初始化题库。

卸载只移除程序与快捷方式，保留客户端资料和 Docker 数据卷。完整备份需要同时保留客户端 `backend/.env` 中的加密密钥，以及 PostgreSQL、Temporal 和 MinIO 的一致备份；仅复制 EXE 不是题库备份。不要用别人的资料目录覆盖自己的配置。
