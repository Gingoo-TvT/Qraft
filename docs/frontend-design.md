# Qraft 工作区界面

Web 与 Windows 桌面复用 Header、Sidebar、页面布局、业务页面、工作台和语义颜色。桌面只额外提供服务连接、原生文件操作与客户端设置。业务页面通过同一套服务 API 处理生成、审核与去重。

## 页面结构

- 工作台：直接填写出题想法，选择单道编程题、混合题集或纯编程比赛；示例只填充需求，进入创建页确认后才生成。
- 创建页：主区编辑需求、题型、难度与范围，侧栏展示由表单计算的摘要和提交动作；模型覆盖、运行参数等按需展开。
- 内容库：筛选、结果、分页放在一个列表区域。题集当前加载范围内的筛选明确标示，不冒充全库检索。
- 题目详情：默认阅读题面，解法、测试数据、质量审核与元信息分视图查看。切换视图保留编辑状态。
- 任务详情：仅展示后端提供的状态、步骤和事件；不推算虚假的完成百分比。
- 模型设置：生成、验算、评审与去重分别编辑，标签切换保留未保存内容。

## 公共实现

- `frontend/src/components/layout/Header.tsx`、`Sidebar.tsx`：两端共用导航与顶部搜索，桌面通过扩展入口提供原生操作。
- `frontend/src/components/workspace/WorkspaceHome.tsx`：两端共用工作台。
- `frontend/src/components/ui/Workspace.tsx`：页头、分区、空状态与表单章节。
- `frontend/src/components/ui/ViewTabs.tsx`：支持键盘导航且保留内部状态的内容视图。
- `frontend/src/styles/workspace.css`、`home.css`、`detail.css`：布局、间距与响应式规则。
- `frontend/src/hooks/useEditorTheme.ts`：编辑器跟随当前主题；切换主题不替换文档模型。

新增业务页面优先复用这些组件。主要按钮用于当前页面的核心动作；原始 JSON、内部运行标识和低频参数收进详情区。表格在自己的容器内滚动，小窗口表单改为单列。

## 配色扩展

六套内置配色位于 `frontend/src/desktop/themes.ts`，Web 与桌面共同读取：石墨、海湾蓝、鸢尾紫、松林绿、玫瑰、琥珀。每套包含浅色和深色颜色，也可跟随系统明暗模式。

页面使用语义变量：`--db` 背景、`--dp` 表面、`--ds` 侧栏、`--dt` 正文、`--dm` 次要文字、`--dl` 边线、`--da` 可读强调色、`--dg` 选中背景、`--d-button` 主按钮。不要在新页面重复写整套颜色或复制两份明暗布局。

添加内置配色时，在 `BUILTIN_THEMES` 增加一项并提供两套完整颜色，同时将相同 ID 加入 `desktop/internal/app/themes.go` 的 `builtinThemeIDs`；主题选择器自动列出。桌面保留主题 JSON 导入、导出与自定义能力，格式与校验见[桌面主题使用与扩展](desktop-themes.md)。

Web 偏好存于当前浏览器的 `algoforge_web_appearance`，兼容旧明暗偏好；桌面偏好由本地客户端保存。二者不相互覆盖。首页传递的 `brief` 是一次性输入，桌面保存启动页时会移除它，避免保存过长的需求 URL。桌面路由切换时内容区回到顶部，避免进入页面时标题隐藏；主题与详情视图切换保留当前输入。

## 验证

修改后运行 `npm run lint`、`npm run build` 和 `npm run build:desktop`。界面回归应覆盖主题切换、未提交输入保留、首页需求传递、连续搜索、详情视图、错误状态及窄窗口。使用模拟接口时需明确标识测试边界；模拟提交只能检查界面交互；模型生成、沙箱执行和文件导出需要另外连接真实服务验证。

桌面新安装默认使用海湾蓝，与 Web 一致；已保存配色保持不变。顶部 Ctrl K 搜索编程题，Ctrl Shift K 打开桌面快捷操作，Ctrl N 创建题目，Ctrl Shift N 创建题集。桌面额外保留客户端设置、原生导出和连接状态；这些功能不再建立另一套业务导航。界面对照应使用相同窗口尺寸、主题、数据状态和滚动位置。
