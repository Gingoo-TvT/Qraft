# Qraft 标签参考

本文列出 Qraft 初始工作区的预置标签（tag），分为 **语法层级 (Syntax)** 和 **算法层级 (Algorithm)** 两大类。每个标签附带中文名称、所属层级、描述、典型难度范围及常见题型。

> 难度分段：入门 (< 800) | 基础 (800-1199) | 中等 (1200-1599) | 提高 (1600-2099) | 省选 (2100-2599) | 专家 (2600-3500)

---

## 一、语法层级 (Syntax)

当前预置 8 个语法与数据结构基础标签，生成参数的难度范围为 800–1200。标签用于组织内容；实际可用项可通过 `GET /api/v1/tags?level=syntax` 查询。

| tag_name | 中文名称 | 内容 |
| --- | --- | --- |
| `grammar` | 语法 | 变量、类型、输入输出、条件、循环与函数 |
| `ds-linear-list` | 线性表 | 数组、链表及基本操作 |
| `ds-stack` | 栈 | 栈、表达式求值与括号匹配 |
| `ds-queue` | 队列 | 队列、循环队列与优先队列基础 |
| `ds-string` | 字符串 | 字符串处理、匹配与操作 |
| `ds-tree` | 树 | 二叉树遍历、构建与基本性质 |
| `ds-graph` | 图 | 图的存储、DFS/BFS 与基本概念 |
| `ds-sorting` | 排序 | 冒泡、选择、插入、快排与归并 |
