# Qraft · 题构 V2.2.1

V2.2.1 修复 Windows 客户端在本机后端尚未就绪时，点击业务入口却显示“客户端设置”的问题。本次为客户端补丁，继续使用已发布的 **V2.2.0 后端**。

## 修复内容

- **页面按所选入口正常打开。** 本机后端未启动或正在启动时，工作台、创建题目、题集与题库等页面不再被客户端设置替换；页内提供连接提示与状态刷新入口。
- **连接恢复时保留当前输入。** 停留在同一页面时，服务连接状态变化不再重建整个页面，已填写的需求得以保留。这不等于关闭客户端或离开页面后的草稿保存。
- **标签可原地重试。** 创建题目页加载标签失败后，可点击“重新加载标签”，无需刷新整页或重新填写需求。

浏览页面和填写需求可以先进行；读取题库、保存配置和提交任务仍需服务可用。

## 升级方式

- **从 v2.2.0 升级：** 在 **客户端设置 → 关于 → 客户端更新** 检查并下载更新，保存当前编辑内容后安装并重启；也可手动下载安装版或便携包。
- **从 v2.1.0 升级：** 该版没有内置更新，首次需手动安装新版。便携版关闭程序并备份原目录后替换程序文件，保留原 `data-qraft` 和 `portable.flag`。
- **已有 V2.2.0 后端：** 无需重新导入镜像包、停止服务或重建题库。客户端更新保留原连接和资料目录，后端任务继续运行。
- **后端仍早于 V2.2.0：** 统一搜索需要 V2.2.0 接口；按 [V2.2.0 升级说明](https://github.com/Gingoo-TvT/Qraft/blob/v2.2.0/docs/releases/v2.2.0.md) 备份并升级，或交由管理员处理。客户端内更新不会升级后端。

[前往 Release 下载](https://github.com/Gingoo-TvT/Qraft/releases/tag/v2.2.1)。连接已有服务的使用者只需客户端；安装版和便携版附带 WebView2 安装引导程序，缺少 Runtime 时需联网安装。完整步骤见 [Windows 使用指南](https://github.com/Gingoo-TvT/Qraft/blob/v2.2.1/docs/windows-desktop.md)。

发行包不包含实例配置、密钥、用户题库或任务数据。此次补丁不改变可信团队共享工作区、账号与权限能力的现有边界。
