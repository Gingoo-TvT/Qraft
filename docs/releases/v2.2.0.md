# Qraft · 题构 V2.2.0

V2.2.0 让编程题与客观题共用一个搜索入口，补齐客户端内更新，并修复 Windows 缩放和创建页布局。以下为相对 v2.1.0 的变化。

## 本次更新

### 统一检索题库

- 顶部入口改为 **搜索题目**，在同一结果页检索编程题与客观题。
- 支持题号、标题、标签与知识点的部分文字匹配，不区分字母大小写。
- 支持题型、标签、知识点、难度组合筛选及统一分页；翻页、返回与刷新保留搜索条件。
- 保留编程题原有的 800–3500 评分和客观题的简单/中等/困难分级，分别筛选，不换算。
- 工作台、题库、题目和题集页面显示搜索；模型配置、去重服务、客户端设置、导出记录等工具页面隐藏入口。`Ctrl K` 仅在有搜索入口的页面聚焦搜索框。

### 客户端内更新

- 在 **客户端设置 → 关于 → 客户端更新** 手动检查正式版本；首次启动不会自动联网检查。
- 下载显示进度，支持取消，并校验文件大小与 SHA256。
- 安装后重启，继续使用原连接、外观设置和资料目录；替换前备份原程序，失败时尝试恢复。
- 更新只更换 Windows 客户端，不会升级或停止后端，也不会中断后端正在执行的任务。

### 窗口与创建页修复

- Windows 窗口按显示器缩放比例和可用工作区域计算大小，切换不同缩放比例的显示器时调整窗口。
- 创建页摘要与操作按钮随内容滚动，避免在较矮窗口或标签较多时被遮挡。Web 与客户端共用此修复。

## 从 v2.1.0 升级

1. **先手动升级客户端。** v2.1.0 没有内置更新入口。保存编辑内容并关闭旧客户端，再运行新版安装包；便携版备份原目录后替换程序文件，保留 `data-qraft` 与 `portable.flag`。
2. **为统一搜索配套升级到 V2.2.0 服务端。** 连接已有服务时由管理员处理；旧后端没有统一搜索接口时，客户端会提示升级，并提供原题库入口。
3. **升级后端前等待任务结束并备份。** 自行部署者应保留客户端 `backend/.env` 中的加密密钥，以及 PostgreSQL、Temporal、MinIO 的一致备份，再安全停止服务、导入同版本后端包并重新启动。客户端内置更新不会完成这一步。

本次升级不新增数据库迁移，也不要求重建题库。不要用他人的资料目录覆盖自己的配置；替换前的 EXE 备份不等于题库备份。

## 分发与使用边界

发行包保持纯净：不包含服务地址、模型密钥、用户题库、任务记录或实例数据库。首次运行由使用者选择自行部署或连接已有服务；新建后端仅包含程序所需的基础字典与规则。

Qraft 面向个人或可信团队共享工作区，尚无完整账号登录、多租户权限隔离或公网访问网关。此次更新不改变这些边界，也不自动合并不同实例的题库。
