# Qraft · 题构 V2.3.0

V2.3.0 将团队账号、来源导入、题目评估和近期网页修复纳入配套的 Windows 客户端与后端发行包，并修复隔离题目无法人工审核通过的问题。

## 本次更新

- **人工审核可覆盖自动质量拦截（#17）。** 管理员确认当前题目后，可以发布缺少题解或自动验题未通过的题目。系统保留原始结果，另存审核人、时间和被覆盖的检查项；普通成员无此权限。内容、程序、测试数据或审核证据变化后，旧决定失效，需要重新审核。自动审核不会使用人工覆盖，导出仍核对实际数据文件。
- **来源难度与人工评价（#8）。** 外部导入保留原站分数或等级。在支持范围内优先采用 Codeforces 原站分数，其他平台保留原尺度，基于已有来源题目与人工正式评分校正后续生成和导入。重复来源不重复计入，自动估值不会覆盖人工确认值。真实跨站准确率和人类试点仍由 #10 跟进。
- **团队共享账号（#11）。** 管理员邀请注册，支持登录、会话撤销、改密和账号管理；共享题库，任务按账号隔离。Web 与新版桌面使用同一登录流程。
- **入门题数值难度（#15）。** 普通算术题避免无关的浮点表示陷阱；主解与独立解法共同核对来源样例，持续不一致则拒绝入库。
- **题库操作修复（#12–#14、#16）。** 保留列表筛选及分页，修正低分原题编辑校验、题集导出编号，以及 Markdown 图片显示。
- **导入与导出。** 外部链接、粘贴题面、分批导入和重试，以及通用 ZIP / Hydro 测试导出均包含在本次正式配套包中。

## 升级

1. 备份客户端资料、服务配置、业务数据库、任务数据库和对象文件，等待在途任务结束。
2. **连接已有服务：** 更新到 V2.3.0 客户端；管理员更新配套服务。保存 HTTPS 根地址后，使用受邀账号登录。旧 V2.2.x 客户端不具备完整共享账号流程。
3. **本机部署：** 保留原 `data-qraft` 和已有 Docker 数据卷，导入 `Qraft-2.3.0-backend-linux-x64.tar.gz` 并升级；不要建立第二个实例来替换已有数据。客户端内置更新只更换客户端，不自动升级后端。
4. **源码部署：** 使用 `v2.3.0` 的配套 API、worker、Web 和迁移镜像，先运行数据库迁移再启动应用。本版本包含迁移 034–036（旧版本已执行的会跳过）；036 增加不可变人工审核记录，不批量修改题库内容。

共享服务首次使用账号模式时按[账号指南](../shared-service-auth.md)初始化管理员；原先公开的旧服务应同时配置 HTTPS 与账号模式。本机独立桌面实例继续使用仅监听本机的个人工作区。

历史题目不会因为升级自动重算难度、重新生成测试或批量解除隔离。原始质量证据保留，人工通过不等于自动验证已经通过。#10 的真实人类试点不作为本次发行已完成事项。

| 文件 | 用途 |
| --- | --- |
| `Qraft-2.3.0-windows-x64-setup.exe` | Windows x64 安装版 |
| `Qraft-2.3.0-windows-x64-portable.zip` | 便携版，解压后运行 Qraft.exe |

安装版与便携版附带微软签名的 WebView2 安装引导程序；缺少 Runtime 时需要联网安装。发行包不含实例配置、密钥、题库或任务数据。详见[Windows 指南](../windows-desktop.md)、[公网部署](../cloud-deployment.md)和[完整变更](https://github.com/Gingoo-TvT/Qraft/compare/v2.2.1...v2.3.0)。
